# HTTP errors

Explore HTTP statuses, error boundaries, and navigation behavior through React Pages API examples.

From the repository root:

```sh
vp run --filter ./playground/http-errors dev
```

Run the HTTP and browser scenarios from the repository root:

```sh
vp test run packages/void/test/integration/http-errors-playground.test.ts
```

The suite runs an isolated copy in development and production, covering response statuses,
error boundaries, document loads, client navigation, deferred streaming, and prefetching.
