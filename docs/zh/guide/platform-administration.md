# 平台管理 {#platform-administration}

通过 `void platform`，你可以在终端中管理 Void 平台上的成员和应用，包括为团队成员授予访问权限、查看项目、跟踪部署日志，以及检查平台运行状况。

管理用户、项目、部署和系统状态的运维命令需要管理员账号。连接平台和管理安装生命周期的命令则各自有相应的认证流程。如果你是首次搭建平台，请先阅读[安装 Void 平台](/zh/guide/self-hosted-platform)。
