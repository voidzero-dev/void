# 开发 Void 平台 {#developing-a-void-platform}

框架、CLI 和平台源码都在同一个仓库中。你可以修改平台、在本地测试，再将基于自己 fork 构建的运行时部署到自己的 Cloudflare 账号。

如果只是使用已发布的平台版本，请从[安装 Void 平台](/zh/guide/self-hosted-platform)开始。管理已安装的平台时，可以参阅[平台管理](/zh/guide/platform-administration)。
